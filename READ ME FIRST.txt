WINDOWS
Extract Lexicon Scholasticum Windows.zip. Keep the entire extracted
Lexicon Scholasticum folder together and open Start Lexicon.cmd. It checks
Microsoft Edge WebView2 Runtime, .NET Framework 4.x and the bundled files.
No separate Python installation is needed. See Windows startup help.txt.

MAC
Extract Lexicon Scholasticum Mac.zip. Move Lexicon Scholasticum.app into
Applications and open it. This contains the same bundled runtime setup
used by the previous working Mac package, for Intel and Apple Silicon.
No separate Python installation is needed. This is an unsigned app;
if macOS blocks it, use Privacy & Security > Open Anyway after attempting
to open it. The package was checked on Windows, not launch-tested on a Mac.

UPDATES
Close the old app before replacing it. On Mac, replace the app in
Applications. On Windows, replace the entire app folder with the newly
extracted folder. Personal libraries and progress are kept separately
in the user's account; do not delete those data folders.

The ZIPs include shared dictionaries, reading texts, fonts and source
credits. They include the explicitly requested reading additions, without saved bookmarks or progress.
First launch may take a few minutes to prepare the dictionaries/runtime.

READING DICTIONARY
